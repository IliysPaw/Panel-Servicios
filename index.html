Dictado inteligente

Para que el "Dictado libre" en la pestaña Dictar entienda lo que dictas (incluyendo Spanglish y acento boricua), necesitas tu propia clave de API de Anthropic. Se obtiene gratis en console.anthropic.com → API Keys, y el costo por cada dictado es una fracción de centavo. La clave se guarda solo en este teléfono, nunca sale de aquí salvo hacia Anthropic para interpretar el dictado.

Que el respaldo llegue solo a la nube

La app no puede escribir en Google Drive, OneDrive o iCloud sin tu autorización explícita — pero puedes hacer que cada respaldo caiga automáticamente en la nube, apuntando la carpeta de descargas de tu teléfono a una carpeta que ya se sincroniza sola:

iPhone (Safari): Ajustes → Safari → Descargas → elige "iCloud Drive" (o una carpeta dentro de iCloud Drive).

Android (Chrome): Chrome → ⋮ → Configuración → Descargas → cambia la ubicación a tu carpeta de Google Drive (aparece como opción si tienes la app de Drive instalada).
